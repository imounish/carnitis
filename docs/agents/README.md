# Agent Docs Index

This folder contains operational standards for agents working in `carnitis`.

## Recommended Read Order
1. `AGENTS.md`
2. `docs/agents/ARCHITECTURE.md`
3. `docs/agents/ENGINEERING_STANDARDS.md`
4. `docs/agents/TESTING_AND_QA.md`
5. `docs/agents/UI_UX_STANDARDS.md`
6. `docs/agents/GIT_AND_DELIVERY.md`

## When To Use What
- Starting a task: use architecture + implementation plan template.
- Writing/changing code: use engineering standards.
- Adding/changing tests: use testing and QA.
- Building UI: use UX standards.
- Preparing commits/PRs: use git and delivery guide + PR checklist template.

## Existing Planning Integration
Use these repository planning files as canonical planning artifacts:
- `docs/planning/TASK_BACKLOG.md`
- `docs/planning/implementation-plans/*.md`

If a task has no plan yet, create one before coding.
